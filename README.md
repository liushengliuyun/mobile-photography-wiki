# 手机摄影

个人学习仓库：以条目为单位，记录手机摄影的器材、技法、后期与审美笔记，问答沉淀为零散问题的档案。

## 形式说明

- 内容全部为 Markdown，GitHub 原生渲染；条目间用相对链接互跳，本文件即总目录——零构建、零依赖。
- 每卷（文件夹）的 `README.md` 是该卷目录（GitHub 打开文件夹时自动显示）。
- 将来若需要侧边栏导航与站内全文搜索，可无缝升级为 MkDocs Material + GitHub Pages：内容不用动，加一份 `mkdocs.yml` 即可。

## 条目约定

1. 新条目复制 [条目模板](条目模板.md)，文件名用中文，放进对应卷。
2. 条目之间互相链接（如 `[三分法](02-构图与用光/三分法.md)`），链接即导航。
3. 各卷 README 的「条目地图」里：`〔待写〕` = 规划占位，`〔成文〕` = 已有正文；写完把纯文本占位换成链接。
4. 拿不准的内容标「待考」，不要留空段落。
